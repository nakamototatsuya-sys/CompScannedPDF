  📌 このツールについて
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CompScannedPDF は、複合機やスキャナーで作成したスキャンPDFを
PC上だけで圧縮できるデスクトップアプリです。

✅ ファイルは一切外部に送信されません（完全ローカル処理）
✅ iLovePDF・Adobe Acrobat 不要
✅ 無料

⚠️ 対象はスキャンPDFのみです
   Word・Excelから作成したテキストPDFには効果がありません。
   見分け方：
     PDF内の文字をマウスで選択＆コピーできる → テキストPDF（対象外）
     PDF内の文字を選択できない               → スキャンPDF（対象）

  ⚠️ フォルダ・ファイル名に関する重要な注意事項
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

以下のルールを必ず守ってください。守らないと正常に動作しません。

【1】ファイルを置くフォルダのパスに日本語を使わない

  ✅ 良い例：  C:\Tools\CompScannedPDF.pyw
  ✅ 良い例：  C:\Users\john\Documents\CompScannedPDF.pyw
  ❌ 悪い例：  C:\Users\山田\Documents\CompScannedPDF.pyw
  ❌ 悪い例：  C:\ツール\CompScannedPDF.pyw

  → 日本語を含むパスではエラーになる場合があります。
  → Windowsのユーザー名が日本語の場合は
    C:\Tools\ など別の場所に置くことを強くおすすめします。

【2】ファイル名は絶対に変更しない

  ✅ 正しい：  CompScannedPDF.pyw
  ❌ 誤り：    compscannedpdf.pyw    （大文字・小文字が違う）
  ❌ 誤り：    CompScannedPDF.py     （拡張子が違う）
  ❌ 誤り：    PDF圧縮ツール.pyw     （日本語ファイル名）

【3】フォルダ名にスペースを含めない（推奨）

  ✅ 推奨：   C:\Tools\CompScannedPDF.pyw
  ⚠️ 非推奨： C:\My Tools\CompScannedPDF.pyw

  → スペースを含むパスは設定が複雑になります。

  🔧 セットアップ手順（初回のみ）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

------------------------------------------------------------
  Step 1 --- ツールファイルの配置
------------------------------------------------------------

  CompScannedPDF.pyw を以下のフォルダに置いてください：

    推奨場所： C:\Tools\CompScannedPDF.pyw

  C:\Tools\ フォルダが存在しない場合は
  エクスプローラーで C:\ を開いて「Tools」フォルダを作成してください。


------------------------------------------------------------
  Step 2 --- Python のインストール
------------------------------------------------------------

  1. 以下のURLにアクセスしてインストーラーをダウンロード：
     https://www.python.org/downloads/

  2. ダウンロードしたインストーラーを実行

  3. インストール画面の最初に以下の項目が表示されます：
     ☑ Add Python to PATH   ← 必ずチェックを入れてください
                                忘れると後の手順が失敗します

  4. 「Install Now」をクリックしてインストール完了

  5. インストール確認：
     PowerShell を開いて以下を実行：
     > python --version
     「Python 3.xx.x」と表示されれば成功 ✅


------------------------------------------------------------
  Step 3 --- 必要ライブラリのインストール
------------------------------------------------------------

  PowerShell を開いて以下を1行まるごとコピー＆ペーストして実行：

  > pip install pdf2image Pillow pypdf reportlab img2pdf

  「Successfully installed ...」と表示されれば成功 ✅
  ※ インターネット接続が必要です


------------------------------------------------------------
  Step 4 --- poppler のインストール
------------------------------------------------------------

  poppler は PDF を画像に変換するために必要なエンジンです。

  1. 以下のURLにアクセス：
     https://github.com/oschwartz10612/poppler-windows/releases

  2. 最新の「Release-xx.xx.x-0.zip」をダウンロード

  3. ダウンロードした zip ファイルを解凍する

  4. 解凍してできたフォルダ（例：poppler-25.12.0）の中身を確認する
     「Library」「share」などのフォルダが入っているはずです

  5. そのフォルダごと以下の場所に移動して名前を変更する：

     移動先：  C:\Tools\poppler\

     ※ フォルダ名は「poppler」に統一してください（バージョン番号不要）
     ※ 正しく配置できると C:\Tools\poppler\Library\bin\ が存在する状態になります

  6. PowerShell を開いて以下を実行（PATHへの追加）：

     > [Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\Tools\poppler\Library\bin", "User")

  7. PowerShell を一度閉じて新しく開き直す

  8. 動作確認：
     > pdftoppm -v
     「pdftoppm version xx.xx.x」と表示されれば成功 ✅
     エラーが出る場合は手順5のフォルダの場所を再確認してください


------------------------------------------------------------
  Step 5 --- .pyw ファイルの関連付け設定
------------------------------------------------------------

  .pyw ファイルをダブルクリックで起動できるよう設定します。

  (1) Python の実行ファイルの場所を確認する
      PowerShell を開いて以下を実行：

      > python -c "import sys; print(sys.executable)"

      以下のようなパスが表示されます（人によって異なります）：
      C:\Users\john\AppData\Local\Python\pythoncore-3.14-64\python.exe
                                                             ^^^^^^^^^
      表示されたパスをメモしておく。
      末尾の「python.exe」を「pythonw.exe」に変えて使います。

  (2) コマンドプロンプトを管理者として開く
      スタートメニューで「cmd」と検索
      → 右クリック →「管理者として実行」

  (3) 以下の2行を順番に実行する
      ※ (1)で確認したパスをもとに「YourName」の部分を書き換えてください

      1行目（pythonw.exe のパスを指定）：
      > ftype Python.NoConFile=C:\Users\YourName\AppData\Local\Python\pythoncore-3.14-64\pythonw.exe "%1" %*

      2行目（.pyw の関連付け）：
      > assoc .pyw=Python.NoConFile

      2行目の実行後に「.pyw=Python.NoConFile」と表示されれば成功 ✅

  (4) CompScannedPDF.pyw をダブルクリックしてアプリが起動すれば完了 ✅

  🖱️ 右クリックメニューへの登録（オプション）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  設定すると PDF ファイルを右クリック →「Compress with CompScannedPDF」
  を選ぶだけで、そのPDFが自動で読み込まれた状態でアプリが起動します。

  ※ この設定はオプションです。省略してもアプリは通常通り使えます。

  ----

  【手順 1】reg ファイルをメモ帳で開く

    CompScannedPDF-register.reg を右クリック
    →「プログラムから開く」→「メモ帳」

  【手順 2】ファイルの内容を確認する

    以下のような内容が表示されます：

    Windows Registry Editor Version 5.00

    [HKEY_CLASSES_ROOT\SystemFileAssociations\.pdf\shell\CompScannedPDF]
    @="Compress with CompScannedPDF"
    "Icon"="shell32.dll,-46"

    [HKEY_CLASSES_ROOT\SystemFileAssociations\.pdf\shell\CompScannedPDF\command]
    @="\"C:\\Users\\pikum\\...\\pythonw.exe\" \"C:\\Tools\\CompScannedPDF.pyw\" \"%1\""
         ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
         ここが pythonw.exe のパス              ここが CompScannedPDF.pyw のパス

  【手順 3】2箇所のパスを自分の環境に合わせて書き換える

    書き換えのルール：
    ・バックスラッシュ \ は必ず \\ と2つ書く
    ・引用符 " はそのまま残す

    【A】pythonw.exe のパス
      Step 5-(1) で確認したパスの python.exe を pythonw.exe に変えたもの

      例） 確認したパス：
           C:\Users\john\AppData\Local\Python\pythoncore-3.14-64\python.exe
           ↓ reg ファイルへの書き方（\を\\に変換）：
           C:\\Users\\john\\AppData\\Local\\Python\\pythoncore-3.14-64\\pythonw.exe

    【B】CompScannedPDF.pyw のパス
      Step 1 で配置したフォルダのパス

      例） 配置した場所：
           C:\Tools\CompScannedPDF.pyw
           ↓ reg ファイルへの書き方（\を\\に変換）：
           C:\\Tools\\CompScannedPDF.pyw

    【書き換え例】
    （ユーザー名が john、ツールを C:\Tools\ に置いた場合）

    書き換え前：
    @="\"C:\\Users\\pikum\\AppData\\Local\\Python\\pythoncore-3.14-64\\pythonw.exe\" \"C:\\Tools\\CompScannedPDF.pyw\" \"%1\""

    書き換え後：
    @="\"C:\\Users\\john\\AppData\\Local\\Python\\pythoncore-3.14-64\\pythonw.exe\" \"C:\\Tools\\CompScannedPDF.pyw\" \"%1\""

  【手順 4】保存して登録する

    1. メモ帳で上書き保存（Ctrl+S）
    2. CompScannedPDF-register.reg をダブルクリック
    3.「このファイルの情報をレジストリに追加しますか？」→「はい」
    4. 任意のPDFファイルを右クリックして
       「Compress with CompScannedPDF」が表示されれば完了 ✅

  ----

  【登録を解除したい場合】

    スタートメニューで「regedit」と検索して開き、
    左のツリーから以下の順にたどってキーを削除：

    HKEY_CLASSES_ROOT
      └ SystemFileAssociations
          └ .pdf
              └ shell
                  └ CompScannedPDF   ← 右クリック →「削除」

  📖 アプリの使い方

  2️⃣  圧縮モードを選択
       用途に合わせて3つのモードから選んでください。

       ┌──────────────┬──────────┬──────────┬──────────────────────────┐
       │ モード        │ 解像度   │ 画像品質 │ おすすめ用途             │
       ├──────────────┼──────────┼──────────┼──────────────────────────┤
       │ 品質重視      │ 200 dpi  │ 85%      │ 契約書・公式書類         │
       │ バランス      │ 150 dpi  │ 72%      │ メール添付・社内共有     │
       │ サイズ優先    │ 100 dpi  │ 55%      │ アーカイブ・参照用       │
       └──────────────┴──────────┴──────────┴──────────────────────────┘

  3️⃣  予想サイズを確認
       モード選択後、圧縮後の予想サイズが自動で表示されます。
       例）8.92 MB → 約 2.23 MB（約 -75%）

  4️⃣  「圧縮を開始 →」をクリック
       保存先とファイル名を選択して実行。
       完了後に元サイズ・圧縮後サイズ・削減率が表示されます。

Q. 圧縮後にファイルサイズが大きくなった
A. テキストPDF（Wordなどで作成）が対象になっている可能性があります。
   PDFの文字をマウスで選択できる場合はテキストPDFです。
   このツールはスキャンPDFのみ有効です。

Q. ダブルクリックすると「アプリを選択してください」と出る
A. Step 5 の .pyw 関連付け設定が完了していません。
   Step 5 の手順をやり直してください。

Q. ダブルクリックしても何も起動しない
A. PowerShell から直接起動するとエラーの詳細が確認できます：
   > python C:\Tools\CompScannedPDF.pyw

Q. 右クリックメニューに「Compress with CompScannedPDF」が出ない
A. reg ファイルのパスが実際の場所と違う可能性があります。
   メモ帳で reg ファイルを開いてパスを確認・修正後、
   再度ダブルクリックして登録し直してください。

Q. 右クリックから起動するとPDFが読み込まれない
A. reg ファイル内の pythonw.exe のパスが間違っている可能性があります。
   PowerShell で以下を実行してパスを再確認してください：
   > python -c "import sys; print(sys.executable)"
   表示されたパスの python.exe を pythonw.exe に変えて
   reg ファイルを書き直して再登録してください。

Q. 処理が遅い・途中で止まっているように見える
A. ページ数が多いほど時間がかかります。
   15ページで1〜3分程度が目安です。
   画面のプログレスバーで進捗を確認しながらお待ちください。

Q. pip install でエラーが出た
A. Python インストール時に「Add Python to PATH」の
   チェックを忘れた可能性があります。
   コントロールパネルから Python をアンインストールして
   Step 2 からやり直してください。
